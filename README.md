## Getting Started
1. Download v0.24 (or the apk on Android).
2. Extract — portable.
3. Copy `prod.keys` and `title.keys` into `keys/`.
4. Put firmware into `firmware/`.
5. Point Eden at your dump folder.

## FAQ

**Keys and firmware?**
Dump them from a Switch you own. Sharing keys is illegal; Eden ships without them.

**Eden vs archived Yuzu?**
Eden has faster shaders, a newer Vulkan path and daily updates.

**Android?**
Yes — Snapdragon 865+ recommended.
